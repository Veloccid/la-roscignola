# La Roscignola · sito del B&B

Sito Astro con 10 proposte grafiche, calendario disponibilità, prenotazione con pagamento (demo) e area proprietario (`/admin`).

- `npm install` – installa
- `npm run dev` – prova in locale su http://localhost:4321
- `npm run build` – crea il sito in `dist/`

Logo originale in `public/logo/`, foto in `public/foto/`, testi e camere in `src/data/`, dati generali in `src/config.ts`.
Pubblicato su Vercel collegato al repo GitHub `Veloccid/la-roscignola`.
